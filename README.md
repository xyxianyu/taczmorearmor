# TACZ: 更多种类的防弹衣

## 主要功能

- 多种等级防弹衣（胸甲）、配套护腿与军靴等
- 合成材料、插板与工作台修理等系统
- 安装 TaCZ 后，按护甲与枪种对伤害进行减伤（非爆头；具体以游戏内为准）
- 自定义穿戴音效等

> 当前为 Beta：部分内容（如 BT201 相关）可能尚未实装或仍在调整。

---

## 安装

1. 安装对应版本的 **Forge**（1.20.1 / 47.x）。
2. 将本模组的 `.jar` 放入 `.minecraft/mods` 文件夹。
3. （推荐）同时放入 **TaCZ** 的 `.jar`。
4. 启动游戏。
